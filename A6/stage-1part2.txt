  predicate function on it. If it does not pass, move onto the next record. If  
  it does, define a new empty output record and set each attribute using the    
  set () function and the output of the corresponding projection function.      
  Lastly, call recordContentHasChanged (), and append () to the output. A few   
  more key points:                                                              
  1. The selection predicate stems from the selectionPredicate string input,    
  which specifies in the prefix format what the predicate should do. This       
  string input is then passed into the compileComputation() function on a       
  MyDB_Record, to define a function that evaluates this predicate on the record 
  it is defined on.                                                             
  2. The predicate is compiled against the record that is used to define the    
  predicate function (i.e. the one used to call compileComputation()).          
  3. The output record should be defined as a new empty record of the output    
  table, which you can assume to have a schema that matches the projections     
  input. The projections input list specifies, in order, the computations to    
  perform to create each attribute in the output record. You use each           
  projection string to compileComputation() on the record you are iterating     
  over, which returns a function that returns the projection output. You then   
  use this output to set the corresponding attribute in the output record.      
  4. You do not need to ensure that the output’s table schema matches the       
  projections, and you can assume that they always match in number and type. No 
  need to do any checks for this.                                               
  5. recordContentHasChanged () should be called every time before you append   
  an output record to an output table. This is because you change the values of 
  the record’s attributes with set ().
